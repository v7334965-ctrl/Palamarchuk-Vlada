# Лабораторная работа: JavaScript

Открыть файл `index.html` в браузере.

Файлы: `index.html` — текст статьи, `style.css` — оформление, `normalize.css` — базовые стили, `images` — картинки.

В статье 46 разных HTML-тегов и в `style.css` 69 разных CSS-свойств (автоматический предварительный подсчёт).

Для локального шрифта скачать Comfortaa Bold (например, с Google Fonts) и поместить `Comfortaa-Bold.ttf` в папку `fonts`.

Внимание: `normalize.css` — учебная сокращённая версия. Для полного выполнения требования преподавателя нужно заменить файл официальным normalize.css с https://github.com/necolas/normalize.css.
